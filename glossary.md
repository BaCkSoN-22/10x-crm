# Technical Glossary

1. **Authentication** — Authentication checks whether a user is who they claim to be. ქართულად: მომხმარებლის ვინაობის შემოწმება.
2. **Session** — A session represents the user's current signed-in state. ქართულად: სისტემაში შესული მომხმარებლის აქტიური მდგომარეობა.
3. **Validation** — Validation checks whether entered data follows required rules. ქართულად: შეყვანილი მონაცემების სისწორის შემოწმება.
4. **Fetch** — Fetch is a browser function used to make network requests. ქართულად: ბრაუზერის ფუნქცია სერვერთან მოთხოვნის გასაგზავნად.
5. **Endpoint** — An endpoint is a URL where an API resource can be accessed. ქართულად: API-ის კონკრეტული მისამართი.
6. **Request method** — A request method describes the action requested from a server, such as GET or POST. ქართულად: მოთხოვნის ტიპი, რომელიც განსაზღვრავს მოქმედებას.
7. **JSON** — JSON is a text format for representing structured data. ქართულად: მონაცემების ტექსტური ფორმატი ობიექტებისა და მასივებისთვის.
8. **State** — State is the current data used by an application to render its interface. ქართულად: აპლიკაციის მიმდინარე მონაცემები.
9. **Event listener** — An event listener runs a function when an event occurs. ქართულად: მოვლენის მოსმენის მექანიზმი, მაგალითად ღილაკზე დაჭერისას.
10. **Deployment** — Deployment makes an application available in a hosting environment. ქართულად: პროექტის ჰოსტინგზე განთავსება.
